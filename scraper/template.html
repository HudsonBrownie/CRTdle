    • Brand: green on a match; the hint line says so when the series matches too.
    • Type: Consumer, Professional, or Computer Monitor.
    • Size: viewable inches. Yellow within 3".
    • Best input: the best input on the back. RF → Composite → S-Video → Component → RGB → Digital (SDI/HDMI/DVI).

    • Tube: yellow when it's the same tube maker but a different line (Trinitron vs FD Trinitron).
    • Weight: yellow within 20%.
